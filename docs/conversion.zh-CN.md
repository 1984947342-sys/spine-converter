# 转换

转换结果可由目标版本的官方运行时加载，其姿势与源数据在其编辑器中的姿势一致。所有差异都列在[报告](report.zh-CN.md)中。

## 版本

| 小版本 | 最早支持的 beta |
|---|---|
| 3.5 | 3.5.03-beta |
| 3.6 | 3.6.14-beta |
| 3.7 | 3.7.29-beta |
| 3.8 | 3.8.25-beta |
| 4.0 | 4.0.27-beta |
| 4.1 | 4.1.04-beta |
| 4.2 | 4.2.56-beta |
| 4.3 | 4.3.74-beta |

所有正式版导出均可转换。早于该小版本格式冻结的 beta 导出返回 `SPC_ERR_UNSUPPORTED_VERSION`。不带版本的数据无法转换：没有 `skeleton.spine` 的 JSON 骨骼返回 `SPC_ERR_UNSUPPORTED_VERSION`，没有 hash 和版本的二进制（部分早期导出如此）返回 `SPC_ERR_UNKNOWN_FORMAT`。这类骨骼请导出为带版本的 JSON，或手动设置 `skeleton.spine`。

`4.3` 这样的目标版本写出 `4.3.0`。目标与源同属一个小版本时，只有源数据已具备该小版本的最终行为，才保留源的补丁号。较早的导出在同一小版本内转换后得到最终行为和补丁号 0，因此再次转换输出不会有任何变化。

## 步骤

| 步骤 | 作用 |
|---|---|
| 检测 | 从数据中识别格式和版本 |
| 解码 | 将源版本的 JSON 或二进制读入统一的树 |
| 迁移 | 每次迁移一个相邻版本，如 3.8 到 4.0 再到 4.1 |
| 编码 | 写出目标版本的 JSON 或二进制 |

目标能容纳时，未知字段和编辑器数据原样保留。数值保持其 f32 值。JSON 输出始终包含 `skeleton.hash`。

## 改写

运行时修改过部分数据的计算方式，如变换约束的混合、不继承旋转的骨骼上的 IK 以及约束顺序。改写会重组这类数据，通常借助辅助骨骼或约束，使目标运行时得到源姿势。只有在目标运行时的所有用法下都成立时才会改写，包括多轨道混合。

| 模式 | 行为 |
|---|---|
| 默认 | 执行改写，每项报告为 `rewritten`，影响为 `none` |
| `--no-rewrite`、`SPC_FLAG_NO_REWRITE` | 保留源数据结构，需要改写的数据被丢弃或近似，并以补救方式 `rewrite` 报告 |

不满足改写条件的数据会被报告。所有改写及其条件见 [changes/rewrites.md](changes/rewrites.md)（英文）。

## 降级

旧版本目标会丢弃或近似其不具备的功能，如物理、滑块、序列、裁剪模式和变换约束属性。每一项都会连同影响一起报告。

| 影响 | 含义 |
|---|---|
| `editor` | 只丢失编辑器数据，播放结果相同 |
| `control` | 播放结果相同，驱动运行时的代码会看到差异 |
| `pose` | 骨骼、插槽、附件、变形或绘制顺序不同 |
| `render` | 姿势相同，渲染图像不同 |

## 图集

3.5 到 3.8 的图集按位置排列，4.0 及以后的图集使用命名字段。转换图集时写出目标版本的格式。

| 3.8 及更早的图集无法容纳 | 代码 |
|---|---|
| 头部字段 | `atlas.header.dropped` |
| `pma` | `atlas.pma.dropped` |
| 未知的页字段 | `atlas.page.dropped` |
| 自定义区域值、不是四个值的 split、没有四值 split 的 pad | `atlas.values.dropped` |
| 0 或 90 以外的旋转，3.8 之前 | `atlas.rotate.dropped` |
| 裁剪掉的空白，3.7 之前 | `atlas.strip.approximated` |

3.7 按区域裁剪掉的空白映射网格 UV，3.5 和 3.6 则映射到打包后的尺寸。将 3.5 或 3.6 骨骼升级时，除非通过 `--atlas`、`spc_options.atlas` 或绑定的 `atlas` 参数提供图集，否则每个网格都会被报告。提供图集后，未裁剪区域和裁剪但未旋转区域上的网格都能精确转换。

## 导出

工程仍在时，请用该小版本最新的补丁版导出。beta 导出和早期补丁版带有运行时变化，该小版本的最终运行时会以不同方式计算其姿势，转换器会报告或改写这些情况。

3.8.75 的骨骼请用其他 3.8 编辑器重新导出。没有任何运行时记录了 3.8.75 导出器的问题。

| 不同版本间姿势不同的数据 | 版本 |
|---|---|
| 负的变换缩放混合 | 世界模式在 4.0 之前、本地模式在 3.7.74-beta 之前被跳过 |
| 负的变换斜切混合 | 世界模式在 4.3 之前、本地模式在 3.7.74-beta 之前被跳过 |
| 绝对世界变换上的 shearY 偏移 | 4.3 在取模之前加上它 |
| 本地绝对变换上超过 180 的旋转或斜切差值 | 4.2.60-beta 之前被取模 |
| 本地变换下不为 1 的本地缩放 | 4.0.27 之前为相对值，4.3 之前为除法后的绝对值 |
| noScale 骨骼祖先上的负缩放 | 3.6.38 之前的 3.6，3.7.72-beta 之前的 3.7 |
| 经过零的骨骼缩放 | IK 和继承的阈值在 4.1 和 4.3 改变 |
| 祖先上有更晚约束时的约束顺序 | 3.8、4.0.76-beta 之前的 4.0 和 4.3.18 之前的 4.3 会重置更早的结果 |

## 限制

| 情况 | 处理 |
|---|---|
| 没有目标数据能复现的运行时行为，如 4.2 与 4.3 之间的物理积分 | 以补救方式 `runtime` 报告，列于 [changes/needs-a-runtime.md](changes/needs-a-runtime.md)（英文） |
| AnimationState 混合、渲染器，以及运行时设置的骨架位置、缩放和翻转 | 不在范围内 |
| 将输出导入 Spine 编辑器 | 未验证 |
| `.spine` 工程文件 | 不支持 |

3.5 到 4.3 的所有运行时变化、对应的上游提交及处理方式见 [changes/README.md](changes/README.md)（英文）。
