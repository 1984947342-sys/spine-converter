# Changes inside 3.8

An export of an earlier 3.8 editor can pose differently in the final 3.8 runtime. [README.md](README.md) defines the classes and the editor bounds.

| Commit and date | Exports affected | Trigger | Final runtime | Class | Converter | Fixture |
|---|---|---|---|---|---|---|
| [e3bc0822e](https://github.com/EsotericSoftware/spine-runtimes/commit/e3bc0822e12013b6dcb1fb420961cd375b9d224d) 2019-06-19 | 3.8.25-beta | two bone IK with the child at the parent origin, softness with scale not 1 | final solve | report `ik.origin.approximated` pose, rewrite softness for a parent of scale 1 and a child of constant scale, see [rewrites.md](rewrites.md), else report `ik.softness.approximated` pose | `src/migrate/v3_7_v3_8.zig` | `I9-ik-3825` `I9b-ik-softness-child-3825` |
| [203a648ae](https://github.com/EsotericSoftware/spine-runtimes/commit/203a648ae9682869db3379c5bbe0347d6456328d) 2019-12-18 [d94ebeae7](https://github.com/EsotericSoftware/spine-runtimes/commit/d94ebeae7aeefd472a779a569f146644a65a08b2) 2019-12-18 | before 3.8.81, betas included | one bone IK on bones that do not inherit rotation, or do not inherit scale while stretching or compressing, two bone IK at the origin of such a parent | solved from the world transform | rewrite one bone IK to a normal proxy bone, see [rewrites.md](rewrites.md), else report `ik.beta.approximated` pose | `src/convert.zig` `src/migrate/v3_7_v3_8.zig` | `I10-ik-world-38` `q1-ik-proxy-38-43` `q3-ik-proxy-38-38` `q6-ik-proxy-scaled-38` |

## Editor data fixes

Editor data fixes change the export and not the runtime.

| Editor | Fix | Class | Converter | Fixture |
|---|---|---|---|---|
| 3.8.26-beta | 3.8.25-beta binaries write IK keys without softness | the 3.8 codec reads and writes these keys for 3.8.25-beta |  |  |
| 3.8.76 | corrupt JSON and binary exports and IK timelines of 3.8.75 | undetectable, no runtime documents what broke, re-export |  |  |
| 3.8.77 | length of the last curve of a path | undetectable, the data holds the length the old editor computed |  |  |
| 3.8.87 | binary deform timelines when a skin has no attachments | undetectable, the timelines are missing from older exports, re-export |  |  |

3.8.75 is rejected by every official 3.8 runtime since [b67bf992a](https://github.com/EsotericSoftware/spine-runtimes/commit/b67bf992a0349b779aac9f619f027d34e296267c). The converter reads 3.8.75 as 3.8.99.
