# Changes from 3.6 to 3.7

Migrated by `src/migrate/v3_6_v3_7.zig`. [README.md](README.md) defines the classes.

| Main changes |
|---|
| IK compress and stretch |
| event audio |
| negative local transform mixes |
| absolute local shear |
| path spacing |
| fixed position and curve start semantics |

3.6 to 3.7 also maps mesh UVs of stripped regions through the whitespace when the atlas is given, see [rewrites.md](rewrites.md), else reports `atlas.strip.approximated` render. 3.6 to 3.7 rewrites negative local scale and shear mixes. 3.6 skips a local mix that is not positive, so negatives become 0, which 3.7 also skips. This is exact unless keys of one timeline reach both signs, or a Bézier handle takes a segment past zero. Such a mix going to 4.3 gets the slider clamp of `changes/rewrites.md`, and anything else is reported. 3.6 adds an absolute local shear mix to the local pose and not to the applied pose, so the shear never reaches the world transform of that update. spine-libgdx and spine-csharp 3.7 apply the shear, and the oracle patch makes spine-cpp 3.7 do the same. 3.7 scales fixed spacing by the world length over the setup length of each bone and stops scaling percent spacing in chain scale mode. When every spaced bone keeps one constant world scale, the spacing is rewritten by that scale as `changes/rewrites.md` lists, and a scale of 1 needs no change. 3.7 also gives a zero length bone no fixed space, where 3.6 spaces it by the spacing, so fixed spacing along a zero length bone stays reported. 3.7 also scales a fixed position on a constant speed path by the world path length over its setup length, which 4.0 undoes, so a 3.6 source going to 4.0 or later is not reported. 3.6 evaluates a curve at a parameter of at least 1e-5 where 3.7 returns the curve start, and 3.7 takes tangents below a parameter of 1e-3 from the first handle. A path is reported when its position can sit on the path start, which is a whole percent or fixed position 0, or when it rotates by tangents. With the corpus positions moved by 0.0013, spine-csharp 3.6 and 3.7 pose tank-pro and vine-pro identically. `down` drops IK compress and stretch with a report and drops uniform silently when nothing compresses or stretches, because uniform only scales those. Event audio, volume and balance and the skeleton audio path are dropped.
