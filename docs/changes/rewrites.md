# Rewrites

Rewrites run by default, not under `SPC_FLAG_NO_REWRITE` or `--no-rewrite`. Each is reported with its `rewritten` code and impact `none`. With the flag the entry a rewrite would replace carries remedy `rewrite`. Setup values and key values of one sign stay in that sign under every crossfade and additive sum of the same data, so the conditions hold under track mixing. The slider rigs are the exception, outside the range of their keys they hold the end value.

Unconditional rewrites also run under `--no-rewrite`: negative local mixes of 3.7 betas, two bone uniform of 4.0 betas and the lone mixScaleY of 4.1 exports before 4.1.18.

Every rewrite has a fixture in `oracle/fixtures` that differs without the rewrite and matches with it.

The helper rigs change what a runtime sees.

| Change | Effect |
|---|---|
| helper animations named `spine-converter/` and the constraint, bone and axis | listed with the other animations, pose comparison skips them |
| helper bones named `spine-converter/` and the constraint, after every other bone | listed with the other bones, pose comparison skips them |
| scale mix 0 on the old constraint | setting its scale mix at runtime does nothing, the constraint ending in `-scale-mix` holds 1 minus the mix |
| shear dropped from a relative world constraint | setting its shear mix at runtime does nothing, the constraint ending in `-shear-wrap` holds it |
| bone scale outside the scale range of the keys | the rig holds the end value, additive tracks or code going past it differ |
| going down to 4.2 | the sliders report `slider.dropped` |
