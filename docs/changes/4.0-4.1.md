# Changes from 4.0 to 4.1

Migrated by `src/migrate/v4_0_v4_1.zig`. [README.md](README.md) defines the classes.

| Main changes |
|---|
| sequences and sequence timelines |
| deform timelines move under attachment timelines |
| linked mesh `deform` becomes `timelines` |
| transform mixScaleY alone no longer skipped |

Converter names are functions of `src/migrate/v4_0_v4_1.zig` for JSON and of `src/binary/v4_1.zig` for binary. `tools/fetch-runtimes.sh` exports the same refs for the oracle.
