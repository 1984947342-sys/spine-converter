# Changes from 3.5 to 3.6

Migrated by `src/migrate/v3_5_v3_6.zig`. [README.md](README.md) defines the classes.

| Main changes |
|---|
| clipping and point attachments |
| two color tint |
| local and relative transform constraints |
| path spacing scaled by the bone world scale |
| curve start parameter |
| reflection of sheared noScale bones |

3.5 to 3.6 reports length spacing and chain scale spacing, which 3.6 scales by the bone world scale, unless every spaced bone keeps one constant world scale, when the spacing is rewritten as `changes/rewrites.md` lists. 3.5 spaces a zero length bone by its world length plus the spacing where 3.6 gives it 0, so a zero length spaced bone stays reported. Percent spacing in chain scale mode is unchanged from 3.7 on while no spaced bone has zero length, and from 4.0 on in any case, so a 3.5 source going there reports it in neither step. 3.5 clamps length spacing at 0 like 4.3, so a 3.5 source going to 4.3 skips the length spacing rewrite of 4.2 to 4.3, and below 4.3 the lowest spacing, Bézier percents within 0 and 1, must stay above minus the shortest scaled bone length.

3.5 to 3.6 reports a path whose position can sit on the path start, a whole percent or fixed position 0, because 3.5 evaluates a curve start at a parameter of 1e-4 and 3.6 at 1e-5. 3.5 skips the scale mix of a transform constraint for a bone world scale up to 1e-5 where 3.6 only skips 0. That depends on poses between keys, so it is not reported.
